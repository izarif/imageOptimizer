izNative

Library that contains platform-specific code

Building

Only Windows is supported for now

  1. Install Visual Studio 2017 or newer
  2. Install Desktop Development with C++ package using Visual Studio Installer
  3. Download Premake
  4. Build LuaJIT library
  5. Move lua51.lib file to <thisProjectFolderPath>\buildDeps\lua\ folder
  6. Move lua.h, lualib.h, lauxlib.h, luaconf.h files to <thisProjectFolderPath>\buildDeps\lua\ folder
  7. Run x86 Native Tools Command Prompt for VS
  8. Execute the following commands: 
    
> cd <thisProjectFolderPath>
> <premakeExePath> vs2017

    Where <thisProjectFolderPath> is something like C:\Users\zar-s\projects\imageOptimizer\izNative

    Where <premakeExePath> is something like C:\Users\zar-s\soft\premake5.exe

    After executing these commands izn.vcxproj file will be created

  9. Open izn.vcxproj file using Visual Studio
  10. Build as any other project
